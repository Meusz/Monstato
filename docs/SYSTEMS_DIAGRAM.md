## Diagrama de Optimización (Object Pooling)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         OBJECT POOLING SYSTEM                                │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐            │   │
│  │   │ Projectile  │    │   Enemy     │    │  Particle   │            │   │
│  │   │    Pool     │    │    Pool     │    │    Pool     │            │   │
│  │   │             │    │             │    │             │            │   │
│  │   │  [P][P][P]  │    │  [E][E][E]  │    │  [X][X][X]  │            │   │
│  │   │  [P][P][P]  │    │  [E][E][E]  │    │  [X][X][X]  │            │   │
│  │   │  [P][P][P]  │    │  [E][E][E]  │    │  [X][X][X]  │            │   │
│  │   └─────────────┘    └─────────────┘    └─────────────┘            │   │
│  │                                                                     │   │
│  │   Active ◀────────▶ Inactive                                      │   │
│  │                                                                     │   │
│  │   get() ──▶ Activates ──▶ Returns to pool when done                │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  Pool Operations:                                                           │
│  - initialize(size): Create pool with pre-allocated objects                │
│  - get(): Get inactive object, activate it, return it                      │
│  - release(obj): Deactivate object, return to pool                         │
│  - resize(new_size): Adjust pool size if needed                            │
│                                                                             │
│  Benefits:                                                                  │
│  - No instantiation during gameplay                                        │
│  - No garbage collection spikes                                            │
│  - Predictable memory usage                                                │
│  - Better performance with many objects                                    │
└─────────────────────────────────────────────────────────────────────────────┘
```
